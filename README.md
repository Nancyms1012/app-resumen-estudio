# App Resumen de Estudio 📚

Repositorio para el material de estudio y la futura app que genera resúmenes,
puntos clave, flashcards y preguntas de práctica a partir de archivos.

## Cómo subir tu archivo

1. Entra a este repo en GitHub.
2. Clic en **Add file** → **Upload files**.
3. Arrastra tu archivo (PDF, Word, texto…) y haz clic en **Commit changes**.
