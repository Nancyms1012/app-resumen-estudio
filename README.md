# 📚 Asistente de Estudio — Estudios Sociales 9°

App web para estudiar con **pestañas (tabs)**: Resumen, Puntos clave, Flashcards
y Preguntas de práctica.

## Estado actual: Demo estática (Opción B)

Esta versión muestra el contenido del **Unidad 1 · Tema 1 — Las sociedades
medievales** ya generado, para ver cómo queda visualmente. No usa IA todavía.

- `index.html` — estructura y contenido
- `styles.css` — diseño (responsive, en español)
- `app.js` — tabs, flashcards con volteo y quiz autocalificable

## Cómo verla

- **En local:** abre `index.html` en el navegador.
- **En línea (Cloudflare Pages):** conecta este repo en el panel de Cloudflare
  Pages con preset *None*, build command vacío y output dir `/`.
